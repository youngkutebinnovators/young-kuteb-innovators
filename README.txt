YOUNG KUTEB INNOVATORS (YKI) — WEBSITE STARTER
================================================

Files
- index.html: responsive, single-page website
- assets/yki-logo-concept.png: preliminary logo concept image
- Volunteer_Form_and_Contact_Workflow.txt: volunteer response workflow and privacy notes
- Google_Apps_Script.gs: backend that saves form submissions to Google Sheets
- Google_Spreadsheet_Setup_Guide.txt: step-by-step spreadsheet connection instructions

How to preview
1. Extract this ZIP file.
2. Open index.html in a modern web browser.
3. Test on desktop and mobile.

Publish using Netlify Drop
1. Extract the ZIP first.
2. Sign in at https://app.netlify.com/ so you can manage updates.
3. Open https://app.netlify.com/drop.
4. Upload the extracted project folder containing index.html and assets.
5. Copy the exact URL Netlify assigns; do not assume a particular subdomain is available.
6. Test the site on mobile and desktop.

Before public launch
1. Replace the preliminary logo with a community-reviewed final logo.
2. Confirm access to the YKI contact email youngkutebinnovators@gmail.com and secure the account with 2-Step Verification.
3. Create and publish the Google Forms interest form using the included workflow template.
4. Connect the built-in volunteer registration form to a private Google Spreadsheet by following Google_Spreadsheet_Setup_Guide.txt.
5. Replace the Apps Script URL placeholder in index.html with your deployed /exec URL, then upload the website folder again.
6. Test a registration and confirm it appears in the spreadsheet before announcing the form.
7. Keep the spreadsheet private and add an appropriate safeguarding/contact route.
8. Confirm all programme, partner, funding and date claims are accurate.

Important
This is a website starter package, not a published website. It does not create accounts, deploy the Apps Script, grant spreadsheet access, or publish the site automatically. YKI is described as an independent, youth-led initiative in development; this package is not proof of legal registration, partnerships, funding, or active programme delivery.
